GitHub — Private Repos Strategy
You have strong live apps but private repos. Here's exactly what to do.
The situation: Most employers and clients will click your GitHub link. A profile with 0 public repos or only forks reads as a red flag — even if your live apps are impressive. You don't need to open-source everything. You need to show enough to prove you write real code.

What to do (in order of priority):

1. Create a pinned "Portfolio README" repo. Create a special repo named exactly mocech (same as your username). GitHub renders its README.md automatically on your profile page. Use it to link to your live apps, explain your stack, and show the Mozilla RCC achievement. This is free, takes 20 minutes, and makes a profile with 0 public repos look intentional and professional.
2. Publish one carefully curated public repo. Pick the smallest, cleanest, most representative piece of code from any project — ideally a Django utility, an API endpoint pattern, or a standalone script. Strip any sensitive keys or business logic. Write a proper README with setup instructions, a screenshot, and a link to the live app. One well-documented public repo beats ten messy ones.
3. For InvoiceIQ specifically — publish a "demo" version. Since this was a freelance project you can't fully open-source, create a public repo called invoiceiq-demo with: the Django project structure (no business logic), a sample Celery task, the DRF serializer pattern, and a README explaining the architecture. This shows the code thinking without exposing the client's IP.
4. Update your GitHub bio and profile picture. Set your display name to "Moses Mulwa", add "Django & AI Developer · Nairobi, Kenya" as your bio, link to your portfolio, and add your location. A profile with no bio next to a portfolio claiming "production systems" creates cognitive dissonance.
5. On your portfolio — add a GitHub disclaimer. On your Projects page, add one line under the GitHub link: "Most repos are private (client work). See my profile README for architecture overviews." This is honest, professional, and sets expectations before a recruiter clicks.
